# 3D Shorts Studio

iPhoneだけで3Dショート動画を制作するためのPWAプロジェクト。

## 絶対条件

- 動画制作工程にBlenderなどのPC用3Dソフトを使わない。
- 3Dシーン制作・プレビュー・将来の動画書き出しはiPhone上で動作させる。
- PCはアプリのコード開発・GitHub管理に限って使用可能。
- AIは無料で利用できる範囲に限定し、有料APIへ自動切り替えしない。
- 制作プロジェクトは端末内に保存・再開できる構成を目指す。

## 6段階の開発計画

1. **3Dプレビュー基盤** — iPhone向けPWA、縦型3Dシーン、描画・操作・端末検証。
2. **素材・キャラクター** — GLB/glTF読み込み、キャラクターと背景素材ライブラリ。
3. **AIシナリオ生成** — プロンプトからシーン構成データを生成。無料枠のみ・上限超過時停止。
4. **アニメーション・演出** — キャラクター動作、カメラ、物理演算、エフェクト。
5. **音声・字幕** — ナレーション、字幕、BGM、効果音。
6. **動画書き出し** — iPhone内で映像・音声を合成し、動画ファイルとして保存。

## Phase 1の内容

- Vite + TypeScript + Three.js
- iPhone Safari向け縦型9:16プレビュー
- コードから生成した街並み・人物・アニメーション
- タッチドラッグによるカメラ操作
- 再生/一時停止、カメラリセット、FPS表示
- PWA manifest / Service Worker
- GitHub Actionsによる型チェック・本番ビルド検証

## 起動方法

Node.js 22.12.0以上を用意してから実行。

```bash
npm install
npm run dev
```

表示されたURLをiPhone Safariで開く。PCとiPhoneが同じWi-Fiの場合は、Viteが表示するNetwork URLを使う。

本番ビルド：

```bash
npm run build
npm run preview
```

## iPhoneでのPWA追加

1. HTTPSで公開されたアプリURLをSafariで開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. ホーム画面から起動して表示を確認する。

## Phase 1の確認項目

| ID | 確認項目 | 合格条件 | 確認方法 |
|---|---|---|---|
| P1-01 | 起動 | エラー画面にならずアプリが表示 | iPhone SafariでURLを開く |
| P1-02 | 縦型プレビュー | 9:16の枠内に3Dシーンが表示 | プレビュー枠を目視 |
| P1-03 | 3D描画 | 人物・道路・建物・木・街灯が見える | シーンを目視 |
| P1-04 | アニメーション | 人物の手足が動き、自然に上下する | 10秒以上再生 |
| P1-05 | 一時停止/再生 | ボタンで動作が停止・再開 | ボタンを交互に押す |
| P1-06 | カメラ操作 | 左右ドラッグで視点が変化 | プレビューを左右にスワイプ |
| P1-07 | カメラリセット | 初期視点に戻る | 視点変更後にリセット |
| P1-08 | FPS表示 | 数値が更新される | FPS表示を5秒観察 |
| P1-09 | 画面適応 | 縦向きiPhoneで横スクロールが発生しない | Safariで表示・スクロール |
| P1-10 | PWA | ホーム画面から起動できる | Safari共有→ホーム画面に追加 |
| P1-11 | ビルド | GitHub ActionsのBuild Checkが成功 | Actionsの最新実行を確認 |

## 現時点の制限

- 人物はPhase 1用の仮プロシージャルモデル。完成品質のキャラクターではない。
- シーンはデモ用の固定シーン。AIによる自動脚本生成はPhase 3。
- 動画ファイルの書き出しはPhase 6。Phase 1ではプレビューのみ。
- iPhone実機のFPS・発熱・長時間安定性は実機確認が必要。PC上のビルド成功だけでは実機合格にしない。

## ライセンス

このリポジトリのコードは、別途ライセンスを定めるまでは利用条件を確認して扱う。追加する3Dモデル・音声・画像素材は、素材ごとのライセンスを記録する。
