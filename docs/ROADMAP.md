# 3D Shorts Studio 開発ロードマップ

## 最終目標

iPhoneだけで、AIを活用した30〜60秒の高品質な3Dショート動画を制作し、MP4としてiPhone内に保存できるPWAを作る。

## 共通ルール

- 動画制作の全工程（素材準備、シーン制作、アニメーション、音声、レンダリング、書き出し）はiPhone内で完結させる。
- PCはアプリのコード開発・GitHub管理に限って使用する。Blender等のPC用制作ソフトを動画制作工程に使わない。
- ローカルAIを優先し、無料で利用できるクラウドAIも選択肢とする。
- 無料枠・無料モデルのみを使用し、有料APIへの自動フォールバックは禁止。利用上限に達した場合は処理を停止して知らせる。
- プロジェクトは保存・再開可能にする。素材は利用条件・ライセンスを記録する。
- 各Phaseの完了はビルドだけで判断せず、iPhone実機で確認する。

## Phase 1：3Dプレビュー基盤

- iPhone向けPWAの基礎
- Three.jsによる縦型9:16の3Dプレビュー
- プロシージャルな街並み・人物モデル
- キャラクターの基本歩行アニメーション
- タッチ操作によるカメラ制御
- 再生/一時停止、カメラリセット、FPS表示
- PWAとしてホーム画面から起動
- GitHub Actionsによるビルド検証

**完了条件：** iPhoneで3Dシーンを表示・操作・再生でき、PWAとして安定して起動できる。

## Phase 2：動画制作基盤

動画制作エンジンと素材・キャラクター管理を同じPhaseで構築する。AIを使わず、手動操作で動画を完成できる土台を作る。

### 2-A. 動画制作エンジン

- タイムライン制御
  - 再生・一時停止
  - 再生ヘッドの移動
  - 時間・フレーム単位の管理
  - クリップや要素の開始・終了時刻
- 複数シーン切り替え
  - シーンの追加・複製・削除・並べ替え
  - シーンごとのカメラ・背景・登場要素
  - シーン間の切り替え
- 字幕表示・編集
  - テキスト、位置、サイズ、色
  - 表示開始・終了時刻
  - シーン単位の字幕管理
- エフェクト
  - 色調・フィルター
  - フェード等の画面効果
  - シーンや時間に紐づく適用
- MP4書き出し
  - 縦型動画
  - 30秒の動画を出力
  - iPhone内に保存・共有
  - 端末・Safariの対応形式とメモリ制約を実機検証
  - MP4を直接生成できない環境では、別形式をMP4と偽らず、変換手段または非対応を明示する

### 2-B. 素材・キャラクター管理

- GLB / glTF形式の3Dモデル読み込み
- キャラクター素材ライブラリ
- 背景・建物・小物の追加
- キャラクターの着せ替え・変更
- 素材の保存・再利用
- 素材のプレビュー、追加、削除、整理
- 素材ごとの出典・ライセンス情報の管理
- 読み込んだ素材をシーン・タイムラインから利用

### 2-C. プロジェクト管理・統合

- シーン、タイムライン、字幕、エフェクト、素材参照を一つのプロジェクトデータとして保存
- 保存したプロジェクトを再度開いて編集を再開
- 素材を複数シーンで再利用
- 編集中のプレビューと書き出し結果の整合性を保つ
- iPhoneのストレージ・メモリ・発熱を考慮し、長尺処理や失敗時の復旧を設計

**Phase 2の完成条件：AIなしで、3D素材を読み込み・配置し、複数シーン、タイムライン、字幕、エフェクトを編集して、30秒の3D動画をMP4としてiPhone内に保存できる。**

## Phase 3：AIシナリオ生成

- プロンプトから動画シナリオを生成
- シーン構成・尺・登場人物の自動設計
- セリフ・字幕の生成
- カメラ・背景・素材配置の指示データ化
- AI出力をPhase 2のプロジェクトデータへ変換
- ローカルAIを優先し、無料クラウドAIにも対応
- 無料枠の上限超過時は停止し、有料APIへ切り替えない

**完成条件：** プロンプトから編集可能なシーン構成を生成し、ユーザーが内容を確認・修正できる。

## Phase 4：アニメーション・演出

- キャラクターの動作パターン拡充（歩く、走る、話す、驚く等）
- 動作とタイムラインの同期
- カメラワークの作成・自動提案
- 物理演算
- パーティクル、光、煙などの演出
- シーン間トランジション
- AI生成の演出指示を編集可能なデータとして適用

**完成条件：** シーンに応じたキャラクター動作・カメラ・演出を組み合わせ、自然な3D映像を作れる。

## Phase 5：音声・仕上げ

- ナレーション生成・読み込み
- キャラクター音声
- BGM・効果音の追加
- 音量・開始位置・長さの編集
- 音声と口の動きの同期
- 字幕と音声のタイミング調整
- 音声を含めたプレビュー・書き出し

**完成条件：** 映像・字幕・ナレーション・BGM・効果音を同期した動画を作れる。

## Phase 6：自動制作・品質向上

- プロンプトからシナリオ・素材・シーンを自動構成
- キャラクター、背景、アニメーション、カメラ、字幕、音声、エフェクトを統合
- 30〜60秒の動画を自動制作
- 自動生成後に手動で修正できる
- プロジェクトの保存・再開・複製
- MP4書き出しの安定化
- iPhoneでの処理速度、画質、発熱、メモリ使用量の最適化
- 失敗時の再開・復旧

**最終完成条件：** iPhoneだけで、プロンプトを中心に30〜60秒の高品質な3Dショート動画を制作し、必要な修正を加えてMP4で保存できる。

## 推奨するPhase 2の実装順

1. プロジェクトデータ形式と保存・再開
2. タイムラインと再生ヘッド
3. 複数シーン管理・切り替え
4. GLB/glTF読み込みと素材ライブラリ
5. キャラクター・背景・小物の配置と再利用
6. 字幕編集
7. エフェクト
8. iPhone内レンダリング・MP4書き出し
9. 30秒のサンプル動画で全機能を通し検証

この順序は、後からAI生成を追加しても同じプロジェクト形式・タイムライン・素材管理・書き出し機構を使えるようにするためのもの。
